Attaque MITM (Man-in-the-Middle)

Une attaque "Man-in-the-Middle" (MITM) permet à un attaquant d’intercepter et de modifier les communications entre deux parties sans leur consentement.

Terminologie

  • Man-in-the-Middle (MITM) : Un attaquant s'insérant entre deux parties en communication.
  • Interception : Capture des données échangées entre deux entités.
  • Détournement : Modification ou falsification des données interceptées.
  • Point d'accès malveillant : Réseau Wi-Fi falsifié pour tromper les utilisateurs.
  • Certificat SSL falsifié : Faux certificat utilisé pour tromper les navigateurs web.

Comment fonctionne une attaque MITM ?

Une attaque MITM implique qu'un attaquant intercepte et manipule des données transmises entre deux parties qui croient communiquer directement.

  • L'attaquant intercepte la communication à l'aide de techniques comme le détournement DNS ou l'usurpation d'ARP.
  • Une fois inséré, il peut surveiller, modifier ou injecter des informations dans la communication.
  • L'objectif peut être de voler des informations sensibles comme des identifiants, des mots de passe ou des données bancaires.

Types d'attaques MITM

  • Usurpation DNS : L'attaquant redirige le trafic vers un faux site web.
  • Usurpation ARP : Falsifie les adresses réseau pour intercepter le trafic local.
  • Écoute des communications : Capture des données via un réseau Wi-Fi non sécurisé.
  • Attaque SSL Strip : Force une connexion non sécurisée en supprimant le chiffrement SSL/TLS.

Prévention et protection

  • Utilisez des connexions sécurisées (HTTPS) et vérifiez les certificats SSL des sites web.
  • Évitez d'utiliser des réseaux Wi-Fi publics sans VPN.
  • Activez le chiffrement WPA3 sur les réseaux Wi-Fi personnels.
  • Surveillez les connexions réseau pour détecter toute activité suspecte.
  • Déployez des outils comme les pare-feux et les systèmes de détection des intrusions (IDS).
