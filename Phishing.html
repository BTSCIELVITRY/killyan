Phishing : Comprendre les attaques d'hameçonnage

Le phishing (ou hameçonnage) est une cyberattaque qui vise à tromper les utilisateurs pour qu'ils divulguent des informations sensibles, telles que des mots de passe, des numéros de carte bancaire ou d'autres données confidentielles.

Terminologie

  • Leurre : Un e-mail, message ou site web conçu pour paraître légitime afin de tromper les utilisateurs.
  • Site cloné : Une copie malveillante d'un site web légitime utilisée pour collecter des données.
  • Victime : La personne ciblée par une attaque de phishing.
  • Attaquant : Le cybercriminel à l'origine de l'attaque.
  • Ingénierie sociale : Technique utilisée pour manipuler les utilisateurs et les inciter à agir contre leur intérêt.

Comment fonctionne une attaque de phishing ?

Les attaques de phishing suivent souvent ce schéma :

  • Un attaquant envoie un e-mail ou un message contenant un lien ou une pièce jointe malveillante.
  • Le lien redirige la victime vers un faux site web ressemblant à un site officiel.
  • La victime entre ses informations confidentielles, qui sont alors collectées par l'attaquant.
  • Les données volées sont utilisées pour des activités frauduleuses ou revendues sur le dark web.

Exemples de phishing

  • Faux e-mails de banque : Vous demandant de vérifier vos informations de compte.
  • Faux sites de connexion : Ressemblant à des plateformes populaires comme les réseaux sociaux ou les services en ligne.
  • Offres trop belles pour être vraies : Annonçant des gains ou des prix à réclamer.

Prévention et protection

  • Vérifiez toujours l'URL des sites web avant d'y entrer des informations sensibles.
  • Activez l'authentification à deux facteurs (2FA) sur vos comptes importants.
  • Ne cliquez jamais sur des liens ou pièces jointes provenant de sources inconnues.
  • Éduquez-vous sur les techniques de phishing pour reconnaître les signes avant-coureurs.
